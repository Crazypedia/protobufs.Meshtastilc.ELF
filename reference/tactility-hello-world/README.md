# Tactility Hello World Reference

This directory contains the "Hello World" example app from the [Tactility](https://tactility.one/) project, an operating system for ESP32 devices. These files are provided for reference.

## Contents

- `HelloWorld.app.elf`: The pre-compiled ELF binary for the Hello World app.
- `main/Source/main.c`: The C source code for the app.
- `main/CMakeLists.txt`: The CMake configuration for the `main` component.
- `CMakeLists.txt`: The root CMake configuration for the app.
- `manifest.properties`: The app manifest containing metadata.

## Sources

- **Binary**: [Tactility v0.2.0 Release](https://github.com/TactilityProject/Tactility/releases/tag/v0.2.0)
- **Source Code**: [TactilityApps Repository](https://github.com/TactilityProject/TactilityApps/tree/main/Apps/HelloWorld)

## Usage

These files serve as a reference for building and loading external ELF applications on ESP32-based platforms, as implemented in the Tactility OS.
